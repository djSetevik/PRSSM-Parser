`original-profiles.json` содержит восемь эталонных профилей и значений `Ikr`, полученных вызовом `Profile` и `Ikr` в исходной `Ais7PassConditionCore.dll` из предоставленной BearingCapacity (версия 7.14.6498.25825). Для получения эталонов созданы экземпляры `ais7GbBeamType1/2` и последовательно установлены скалярные свойства из соответствующих BDF. Значения координат `PointF` сохранены без округления, в метрах. Файлы моделей находятся в `PRSSM-Parser/Data/BDF`.

Эталоны проверяют реализацию обоих типов сечений, а не вычисляются тестируемым конвертером.

SHA256 исходной DLL: `C957EF682DEED2A074C9B43FE6DEE97A517617B428CB6C6FB4F20EDB6BB4D2E2`.

`legacy-example.bdf` — файл `!Пример.bdf` из той же программы. Проверяет старое написание `RainLow`/`RainTop` и линейные вуты.
